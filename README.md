# Warhammer D&D Character Guide

An accessible, sourcebook-style guide to character creation and advancement for the Warhammer D&D campaign module.

The guide is designed for calm navigation: short summaries first, focused detail pages, searchable sections, class tabs, level-by-level tables, large readable type, spacing controls, high-contrast mode, reduced-motion support, and print styles.

This is a fan-made presentation guide. Warhammer 40,000 names and related intellectual property belong to their respective owners.
